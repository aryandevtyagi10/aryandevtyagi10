## 🌟 Featured Projects

### 🛰️ Telecom NOC AI — Fault Prediction & Predictive Maintenance

**Python · FastAPI · React · TypeScript · PyTorch · XGBoost · scikit-learn · Google Gemini · SQLite · JWT**

An AI-powered Network Operations Center decision-support platform, built on the real Kaggle Telstra Network Disruptions dataset. Not just a classifier — a full detect → predict → explain → diagnose → prevent → remediate pipeline for NOC engineers.

- 🧩 **5-model ensemble** (Random Forest, XGBoost, SVM, LSTM, GRU) for fault severity prediction, F1-weighted soft voting — best individual model (XGBoost) at **72.71% accuracy**
- 🔍 **PyTorch autoencoder** trained on normal-only telemetry for independent anomaly detection, fused into one combined operational risk score
- 🩻 **Explainable AI** feature attribution + a **Gemini-powered NOC Copilot** (root-cause hypotheses, preventive recommendations, remediation plans) with a fully offline deterministic fallback
- 🔐 **JWT-authenticated** dashboard, deployed full-stack (Render + Vercel)
- 🎛️ Includes a live **What-If Network Simulator** — test hypothetical scenarios through the same real ML engine
